## 真实浏览器验收

使用独立本机 `http://127.0.0.1:8080` 工程库进行测试，桌面尺寸 1280 × 800。没有刷新或修改用户已打开的 file:// 原工程窗口。

1. 从空白工程绘制两个矩形，多选出现八柄与旋转柄、上方及右侧两种缩放切换。
2. 分别倍率 150% 后两层分别由约 186 / 197 × 175 变为 279 / 295 × 262；拖右柄后宽约 429 / 455，单独选择核对第一个对象中心 X 仍为 275.5。
3. 整体倍率 120% 后尺寸及间距同步变化；历史为「整体缩放」，一次撤销恢复。验收时发现倍率输入触发重复历史，已修复为仅实际属性控件开始属性快照。
4. 组合、Ctrl+D 复制组合、撤销复制、Ctrl+S 保存；刷新并重新打开，单击一个列表成员恢复两个成员的组合选择。
5. 解除组合；源矩形改为 `#ff4ca7`，K 格式刷后点击另一列表对象，目标色已改变；双击格式刷后连续刷保持激活，Esc 退出。
6. 移动对象到画布中心附近（指针约 X 538）后属性 X 精确为 540（1080 宽画布）；缩放右柄到右边缘附近（指针约 X 1074）后右边缘精确吸附 1080，属性显示中心约 696.4、宽约 767.3。
7. 图层面板、属性面板、画布选框与工具提示正常，控制台没有 error 日志。
